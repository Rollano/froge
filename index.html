Core Features

Designed for fast terminal workflows, seamless device integration, and clean full-screen configuration.

01

Startup Permissions & Storage

Requests required runtime permissions on launch and prepares quick storage shortcuts under ~/storage.

02

Automatic Termux Connection

Detects Termux automatically on startup and connects accessible Termux paths alongside the app prefix without needing an open Termux session.

03

Full-Screen Settings & About

Opens a dedicated full-window Settings screen with an About section via the top-bar Settings button, menu, or commands.

04

Multi-Window Sessions

Create, switch, and manage multiple terminal windows alongside quick command chips and an installed apps drawer.

05

Themes, Fonts & Wallpapers

Personalize UI styles, prompt formats, font families, zoom/font sizes, text/prompt colors, background tint, and custom wallpapers.

06

Packages, Audio & Background

Install/update packages via pkg, inspect system info, play local audio files, and run background session support.

Quick Commands

Common commands you can run directly inside TermLauncher.

sysinfo Environment & prefix info
bin List available binaries
pkg update && pkg install <pkg> Sync & install packages
settings / about Open full-screen Settings & About

Installation & Notes

Helpful details before installing on your Android device.

  • • Enable Install unknown apps for your browser or file manager if sideloading the APK.
  • • Approve startup permission dialogs so notifications and storage shortcuts under ~/storage work smoothly.
  • • Full-screen interactive terminal editors such as nano require a PTY session rather than a non-PTY pipe stream.
